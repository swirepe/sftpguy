# The Talking Machine: 1890–1906

A self-contained offline listening-room experience reconstructing the wonder of early recorded sound. The *audio* is archival; the interface is a clearly labeled modern interpretation.

## Start here
Open START_HERE.html in a modern browser. All three .ogg files must remain beside the HTML file. No web server, dependencies, registration, or internet connection required.

## Contents
- START_HERE.html — interactive, keyboard-accessible listening room, timeline, contextual notes and playback controls
- Big-Ben-1890-Phonograph.ogg — historical phonograph recording of Big Ben
- Edison-Talking-Doll-Jack-and-Jill-1890.ogg — early doll voice
- Edison-I-Am-The-Phonograph-Advertising-1906.ogg — talking-machine advertisement
- MANIFEST.json — sources, rights, source dates, archive paths and verification notes

## Authenticity and limitations
This is not an acoustic or mechanical simulation of the wax-cylinder phonograph. The spinning disc is an interpretive metaphor, and the recorded sound reflects later transfers. Avoid conflating the illustrated apparatus with actual cylinder mechanisms.
